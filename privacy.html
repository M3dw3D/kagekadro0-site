Политика конфиденциальности.

Как персональный инструмент KageKadro0 Shorts использует разрешённые данные Google, хранит техническую информацию и позволяет отозвать доступ.

Последнее обновление: 15 октября 2026 г. / Last updated: October 15, 2026.

1. Кто мы и для чего приложение

KageKadro0 Shorts (также «KageKadro0 AutoPublisher», далее — «Приложение») — личный инструмент владельца YouTube-канала @KageKadro0. Он загружает одобренные короткие видео из Google Drive в YouTube с помощью GitHub Actions и настраивает время публикации. Это не открытая платформа: регистрация сторонних пользователей не предусмотрена.

Сайт нужен для описания инструмента и опубликования этой политики. На сайте нет входа через Google.

2. Какие разрешения запрашиваем

  • YouTube upload (youtube.upload): загружать видео на авторизованный канал и задавать параметры публикации.
  • YouTube read-only (youtube.readonly): проверять идентификатор подключённого канала, историю загрузок и состояние видео, чтобы избегать ошибок и дублей.
  • Google Drive read-only (drive.readonly): скачивать выбранные владельцем MP4 и TXT по их идентификаторам. Разрешение технически допускает чтение файлов Google Drive шире этой выборки, но приложение использует только файлы, явно указанные в утверждённой очереди; оно не удаляет и не меняет содержимое Диска.

Все эти разрешения предоставляются владельцем через официальный экран Google OAuth. Мы не запрашиваем пароль Google.

3. Какие данные используются и зачем

Приложение обрабатывает идентификаторы выбранных файлов, их MP4/TXT-содержимое, названия и описания, идентификатор YouTube-канала, YouTube video ID, статус загрузки, время публикации и технические результаты операций. Данные используются только для проверки канала, чтения выбранных роликов, создания запланированных публикаций и предотвращения дубликатов.

Мы не используем данные Google для рекламы, продажи, профилирования или обучения моделей искусственного интеллекта.

4. Где храним данные

  • OAuth-идентификатор, секрет клиента и refresh token первоначально сохраняются локально у владельца и затем передаются в GitHub Actions Secrets приватного репозитория, не в этот публичный сайт.
  • Выбранные видео и описания временно скачиваются на среду выполнения GitHub Actions для загрузки в YouTube. Постоянное публичное хранилище исходных файлов здесь не создаётся.
  • Идентификаторы публикаций, ссылки и технические квитанции могут сохраняться в приватном репозитории владельца; загруженные видео хранятся в YouTube согласно настройкам владельца и условиям YouTube.

Доступ к Google может быть отозван владельцем. Доступ к приватному репозиторию определяется настройками его владельца.

5. Передача и ограничения использования

Данные обрабатываются с использованием Google Drive, YouTube, Google OAuth и GitHub Actions — исключительно в объёме, необходимом для выполнения описанных задач. Мы не продаём данные и не передаём их рекламным брокерам или сторонним пользователям.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use. Доступ человека к данным ограничен действиями самого владельца и случаями, необходимыми для безопасности, поддержки или соблюдения закона.

6. Отзыв согласия, удаление и сроки хранения

Владелец может в любое время отозвать Google OAuth-доступ в настройках Google-аккаунта. Для прекращения автоматизации также можно удалить секреты из приватного GitHub-репозитория и локальной папки .secrets, отключить workflow и удалить технические квитанции. Исходные файлы удаляются владельцем из Google Drive отдельно; уже загруженные видео — отдельно в YouTube Studio.

Технические квитанции и OAuth-секреты сохраняются, пока нужны для работы или пока владелец их не удалит. Временные данные в рабочей среде GitHub Actions не предназначены для долговременного хранения приложением. Платформа GitHub может иметь собственные журналы выполнения и сроки хранения.

7. Данные посетителей сайта

Сайт статический, не содержит аналитики, сторонних пикселей и JavaScript-трекеров и сам не устанавливает cookies. Хостинг GitHub Pages может технически обрабатывать IP-адреса и журналы запросов по своей политике. Внешние ссылки ведут на сайты третьих сторон, к которым применяются их правила.

8. Контакты и изменения

Вопросы о данных и запросы на изменение можно направлять владельцу приложения через GitHub Issues сайта. Не публикуйте в общедоступных обращениях пароли, токены, личные файлы или другую конфиденциальную информацию.

При изменении процессов обработки эта страница будет обновляться с новой датой редакции.
