## Publishing with GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

This repository contains public website files only. **Do not** commit OAuth credentials, \`.secrets\`, video content, channel uploads, or private automation configuration here. Publishing access to the separate private automation repository stays disabled unless its owner explicitly approves.

The pages use no analytics, tracking scripts, cookies set by the site, or remote fonts.
